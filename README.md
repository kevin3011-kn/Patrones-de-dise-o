
# Patrones de diseño en Java

Repositorio de ejercicios y prácticas de programación orientada a objetos
desarrollados durante mi formación en Ingeniería de Sistemas.

## Temas trabajados

- DAO y DTO
- Factory y Abstract Factory
- Singleton
- Logging
- Ejercicios de POO

## Objetivo

Comprender cómo los patrones de diseño ayudan a organizar las
responsabilidades, reutilizar código y facilitar el mantenimiento
del software.

## Tecnologías

- Java
- Programación orientada a objetos

## Uso

Cada carpeta contiene una práctica independiente. Revisa sus
archivos e instrucciones antes de ejecutarla.

## Nota

Los ejemplos forman parte de ejercicios académicos y no
constituyen por sí solos una aplicación de producción.
